# Mini ERP

## Purpose

A portfolio ERP system built with Laravel.

Goal is demonstrating backend engineering skills through a complete sales and inventory workflow.

## Tech Stack

- Laravel 11
- PostgreSQL
- Docker
- Chart.js

## Architecture

- MVC
- Service Layer
- Repository when needed
- Database transaction for business operations

## MVP

Sales workflow:

Customer
→ Sales Order
→ Order Items
→ Approval
→ Stock Deduction
→ Stock Movement
→ Dashboard

## Not Included

- Accounting
- HR
- Manufacturing
- Multi warehouse
